Deployment configs (one JSON per project) are saved here by the research-bridge skill or by you.
They contain local paths, so .gitignore keeps them out of the repository.
Start from: python deploy.py --example-config --out configs\myproject.json

部署配置（每个项目一个 JSON）由 research-bridge skill 或你自己保存在这里。
里面有本机路径，.gitignore 已把它们排除在仓库之外。
从这里开始：python deploy.py --example-config --out configs\myproject.json
